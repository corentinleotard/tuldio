Quick Replies
Pills vs Rich Cards
Quick reply pills = choix conversationnels (disambiguation client, doublon, confirmation prix OCR)

Rich card actions = actions sur une entité (envoyer devis, consulter facture)

Jamais les deux en même temps. Le tool retourne soit richCard, soit quickReplies.
Comportement
Tap = envoie le texte du bouton comme message utilisateur
Saisie = les pills disparaissent
Une seule fois = uniquement pour le dernier message IA
Variantes
Action positive (primary fill)
Choix neutre (primary outline)
Refus / annulation (muted outline)
