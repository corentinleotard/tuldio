Tuldio — Document Readiness

UX Flow · Mars 2026 · v7b

Contexte
État d'un utilisateur après onboarding

L'onboarding force : nom, SIRET, adresse. Les mentions légales facture ont des valeurs par défaut. La date de validité du devis est auto-calculée (30 jours). Donc au premier document : paramètres entreprise = OK. Le seul problème récurrent = adresse client manquante.

État réel après onboarding
// Forcé par onboarding name "Durand Plomberie" ✓ siret "12345678901234" ✓ address "12 rue des Lilas, 69003" ✓ // Valeurs par défaut (pre-remplies) early_payment_discount "Pas d'escompte..." ✓ late_penalty_rate "3x taux légal" ✓ recovery_fee "40,00 €" ✓ // Auto-calculés validUntil +30 jours ✓ (quote_validity_days) prestationDate aujourd'hui ✓ dueDate +30 jours ✓ (invoice_payment_delay_days) // Probablement vide tva_number "" warning si assujetti
