User Flow
1
Tap mic — input bar transforms to recording mode. Red pulsing dot + timer + live waveform.
2
Speak — waveform animates in real time. Cancel (X) to abort, Stop (square) to finish. Auto-stops after 5s of silence or 60s max.
3
Transcribing — audio is sent to Whisper API. Spinner + "Transcription en cours..." label. Usually under 2s.
4
Review — transcribed text appears in the textarea (editable). User can fix typos, re-record (mic icon), or send (arrow). Textarea auto-grows to fit the text.
5
Send — message enters normal chat flow. AI processes it as any typed message. Input bar returns to idle state.
